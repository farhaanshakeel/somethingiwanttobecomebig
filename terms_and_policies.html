Privacy Policy

Tri-angle collects only the information necessary to operate its features, such as Discord user IDs, role and channel references, and any data you explicitly provide via bot commands (for example, study group names or task entries). By default data is stored locally in the `triangle_data.json` file on the host where the bot runs. The project does not sell personal data. If you deploy Tri-angle with optional external services (for example, Firestore), those services may store additional data according to the host's configuration and the service's policies.

Data Retention & Requests

To request deletion of data stored by a specific server instance, contact the server administrators or the bot owner (contact details below). For deployments that use external services, data removal may require manual steps by the administrators or by the external service provider; follow the deployment's documented procedures.
