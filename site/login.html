Sign in with Discord

Pi-space uses Discord OAuth on the server only. Your Discord password is never seen by this site, and the session is kept in an HttpOnly cookie with a short-lived server-side session record.

  • Only the identify scope is requested.
  • The OAuth state is validated before code exchange.
  • Cookies are HttpOnly, SameSite=Lax, and Secure when HTTPS is enabled.
